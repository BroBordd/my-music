# my-music
Pixel music player for the [vessel](https://github.com/BroBordd/vessel) soundtrack. Streams `music/*.ogg` from the repo, draws notes and drums from the `.vsd` files, with volume, pitch (-20..+20 semitones), loop and a tape-style scrub bar (drag it and the sound plays at the speed of your finger, backwards too).
Hosted with GitHub Pages: no build, one `index.html`.
